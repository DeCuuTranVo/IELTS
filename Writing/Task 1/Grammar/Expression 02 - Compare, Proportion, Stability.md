# Các cách diễn đạt dùng khi so sánh
| number | vietnamese                             | english                                                                                       |
| -----: | -------------------------------------- | --------------------------------------------------------------------------------------------- |
|      1 | **Gần bằng/ xấp xỉ ~**                 | S + **is nearly/roughly equal to ~**                                                          |
|      2 | **~ được phân bổ tương đối đều**       | S + **is relatively evenly distributed**                                                      |
|      3 | A **cao/thấp/nhiều ~ hơn** B           | A **is + dạng so sánh hơn của tính từ (higher, lower, more, less ~) than B**                  |
|      4 | A **~ nhất**                           | A **is + dạng so sánh bậc nhất của tính từ (the most common/ the most popular/ the highest)** |
|      5 | **Theo sau là ~**                      | **followed by** ~                                                                             |
|      6 | **Bám sát theo sau với**               | Clause + **close behind**                                                                     |
|      7 | **Tăng/giảm khoảng cách**              | **The gap widens/narrows**                                                                    |
|      8 | **So với ~**                           | **Compared to** ~                                                                             |
|      9 | **Trái lại,**                          | **In/By contrast,**                                                                           |
|     10 | **Thấy được xu hướng/xu thế tương tự** | **A similar pattern/trend was seen**                                                          |
|     11 | **Trong khi**                          | **Whereas** + clause                                                                          |
|     12 | **... hơn ~ cộng lại**                 | Clause + **more + N + than ~ combined**                                                       |
|     13 | **Nổi bật/ thấy rõ**                   | S + **stand out**                                                                             |
